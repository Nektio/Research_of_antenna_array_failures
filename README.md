# Симулятор антенной решётки

Программа для моделирования плоской фазированной антенной решётки (ФАР) с различными типами излучателей, амплитудными распределениями и фазовым сканированием.

## Возможности

- Расчёт ДН одиночного излучателя (пирамидальный рупор, конический рупор, диполь, патч, изотропный)
- Построение ДН решётки с учётом множителя решётки
- Фазовое сканирование по двум осям (H и E)
- Амплитудные распределения: равномерное, косинусное, косинус на пьедестале, треугольное, гауссово, квадратичное
- Моделирование отказов элементов
- Компенсация отказов с физическим ограничением мощности
- Визуализация амплитудного и фазового распределения
- Сравнение ДН до и после отказов
- Конструктор излучателей с валидацией параметров
